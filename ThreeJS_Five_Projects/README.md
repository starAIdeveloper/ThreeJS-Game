# Five Three.js Projects

Five standalone browser projects: campus viewer, kitchen planner, point-cloud viewer, product configurator and solar system.

In any project folder, run `npm start`, then open the printed local URL. Run `npm test` for its automated source and HTTP checks. Rendering requires an internet connection for the pinned Three.js CDN imports.

## Commit history

Each project's three development commits were imported in order into this repository, with the original commit SHA recorded in each message. GitHub assigns new commit IDs and metadata to the imported commits. The original authors, timestamps and commit IDs remain in `history/*.bundle`. Restore one using `git clone history/threejs-campus-viewer.bundle restored-campus-viewer` (adjust the name for other projects).

These projects were created with AI assistance. Automated checks pass; real-device and visual WebGL testing remain to be performed.
